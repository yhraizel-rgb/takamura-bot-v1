comment ça marche
01

Saisir le numéro

Indiquez le numéro au format international (exemple : 2376XXXXXXXX).

02

Générer le code

Cliquez sur « Générer ». Un code à 8 caractères apparaît en quelques secondes.

03

Associer sur WhatsApp

Ouvrez WhatsApp, allez dans « Appareils connectés », choisissez « Associer avec un numéro de téléphone » et saisissez le code.

04

Connexion établie

Le bot se connecte automatiquement dès que le code est validé.

Mode d'emploi

Suivez ces étapes pour configurer et utiliser Takamura Bot correctement.

étape 1 — pairage

Connectez votre compte via la section Pairage. Le code généré doit être utilisé immédiatement, il expire au bout de quelques minutes.

étape 2 — activation des fonctionnalités

Depuis WhatsApp, envoyez une commande de type .autoread on pour activer une fonctionnalité. Utilisez off pour la désactiver.

étape 3 — commandes du bot

Toutes les commandes commencent par le préfixe défini (par défaut : .). Consultez la section « Commandes » pour la liste complète des commandes disponibles et « Fonctionnalités » pour les options activables ou désactivables à la volée.

Fonctionnalités

Ces options s'activent et se désactivent avec .nom on / .nom off depuis WhatsApp.

autoread
Lecture automatiqueMarque les messages reçus comme lus dès leur arrivée.
autoreact
Réaction automatiqueRéagit avec un emoji aléatoire à chaque message reçu.
autotyping
Simuler la frappeAffiche « en train d'écrire… » dans les groupes.
autorecording
Simuler l'enregistrementAffiche « en train d'enregistrer un vocal… » dans les groupes.
welcome
Message de bienvenueSalue automatiquement chaque nouveau membre d'un groupe.
bye
Message de départSignale quand un membre quitte le groupe.
antilink
Anti-lienBloque le partage de liens dans les groupes protégés.

Commandes

Commandes disponibles avec le préfixe par défaut « . ». La liste se met à jour selon les commandes présentes dans le dossier /commands.

.autoread
on / offActive ou désactive la lecture automatique des messages.
.autoreact
on / offActive ou désactive les réactions automatiques.
.welcome
on / offActive ou désactive les messages de bienvenue en groupe.

Ajoutez vos propres commandes personnalisées dans le dossier /commands du serveur ; elles apparaîtront automatiquement ici après redémarrage.

FAQ

Questions fréquentes sur Takamura Bot.

Le code de pairage a expiré, que faire ?
Retournez dans la section Pairage et générez un nouveau code, puis saisissez-le immédiatement dans WhatsApp.
Le bot se déconnecte régulièrement
Vérifiez votre connexion et évitez de vous connecter au même numéro depuis plusieurs appareils WhatsApp Web en même temps.
Comment changer le préfixe des commandes ?
Le préfixe se configure côté serveur dans la configuration du bot (valeur par défaut : « . »).
