Bienvenue sur TAKAMURA BOT

Console de gestion pour votre bot WhatsApp. Connectez un compte, consultez la documentation et pilotez vos fonctionnalités depuis une interface unique.

Démarrage rapide

Connecter votre compte

Rendez-vous dans la section « Pairage », entrez votre numéro au format international et récupérez un code à saisir sur WhatsApp pour activer le bot.

Documentation

Guide d'utilisation, fonctionnalités et commandes disponibles.

FAQ

Réponses aux questions les plus fréquentes.

Pairage du bot

Entrez le numéro WhatsApp du bot au format international, sans espaces ni symbole « + ».

Comment ça marche
01

Saisir le numéro

Indiquez le numéro au format international (exemple : 2376XXXXXXXX).

02

Générer le code

Cliquez sur « Générer ». Un code à 8 caractères apparaît en quelques secondes.

03

Associer sur WhatsApp

Ouvrez WhatsApp, allez dans « Appareils connectés », choisissez « Associer avec un numéro de téléphone » et saisissez le code.

04

Connexion établie

Le bot se connecte automatiquement dès que le code est validé.

Mode d'emploi

Suivez ces étapes pour configurer et utiliser TAKAMURA BOT correctement.

Étape 1 — Pairage

Connectez votre compte via la section Pairage. Le code généré doit être utilisé immédiatement, il expire au bout de quelques minutes.

Étape 2 — Activation des fonctionnalités

Depuis WhatsApp, envoyez une commande de type .autoread on pour activer une fonctionnalité. Utilisez off pour la désactiver.
